# Electronic Billing System

A Java-based desktop billing and inventory management application designed
for electronic shops.

## Features

- User Login & Authentication
- Admin Panel
- Retail Billing
- Wholesale Billing
- Customer Management
- Product Management
- Inventory Management
- Invoice Generation
- Invoice History
- Sales Analytics
- Warranty Management
- User Management
- Shop Settings
- Password Management
- Serial Number Management
- JSON-based Data Storage

## Technology Stack

- Java
- Java Swing
- JSON
- Object-Oriented Programming
- File-based Data Storage
